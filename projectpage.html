Project Title: K's Budgeting (Java Swing Budgeting Application)

Status: Completed

This was my 1st experience of creating software. K's Budgeting is a budgeting application that allows users to set an income cycle, pseudo bank accounts, and expenses to outline a budget that can be used to help users to budget in their real lives to potientially increase their financial stability. This was my high school computer science capstone project, submitted for the International Baccalaureate (IB) Internal Assesment for IB Computer Studies: Standard Level. It was 100% developed and designed by me, like this website. It is comprised of 100% Java and more specifically, its Java Swing package, to give it GUI capabilites. It requires a code complier to run as it is not an actual application that is downloadable on your phone or computer. That would have been way outside the scope for the project. Overall, this project gave me firsthand experience into the software development process which included: crafting each block of code of the application, putting them together in a meaningful and efficient way, expressing the code through a GUI and, thoroughly documentating each step.
